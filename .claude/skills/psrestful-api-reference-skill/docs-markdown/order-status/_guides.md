# Order Status API

## Service Overview

Track order status and get available status types from suppliers.

## Endpoints & Functions

| Function                  | Purpose                                                       | Guide                                                    |
| ------------------------- | ------------------------------------------------------------- | -------------------------------------------------------- |
| `getOrderStatusDetails()` | Get order status (by PO, SO, last update, or all open orders) | `guides_order-status_how-to-get-order-status-details.md` |
| `getOrderStatusTypes()`   | Get available order status types for a supplier               | `guides_order-status_how-to-get-order-status-types.md`   |
