# Purchase Order (Send PO) API

## Service Overview

Submit purchase orders to suppliers for blank, configured, or sample goods.

## Endpoints & Functions

| Function                | Purpose                                                 | Guide                                                     |
| ----------------------- | ------------------------------------------------------- | --------------------------------------------------------- |
| `sendPO()` (Blank)      | Place a purchase order for blank (undecorated) goods    | `guides_purchase-order_send-po_place-blank-order.md`      |
| `sendPO()` (Configured) | Place a purchase order for configured (decorated) goods | `guides_purchase-order_send-po_place-configured-order.md` |
| `sendPO()` (Sample)     | Place a purchase order for samples                      | `guides_purchase-order_send-po_place-sample-order.md`     |
